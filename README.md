# Chinmayi Ghosh — Portfolio

An interactive, fine-dining-inspired portfolio website for **Chinmayi Ghosh**, a
multilingual hospitality and customer-experience professional.

## Highlights

- **Fine-dining aesthetic** — charcoal, cream & gold palette, Cormorant Garamond
  serif display, a "tasting menu" structure (the career told in three courses).
- **Custom morphing cursor** that changes with the story:
  - ✈️ **plane** while reading her aviation work (IndiGo)
  - 🥐 **pastry** for her patisserie season in France
  - 🍷 **wine glass** for her fine-dining reservations work
- **Ambient theming** — the background mood shifts per course.
- **Interactive personality analysis** — a Big Five (OCEAN) reading with animated
  pour-to-fill trait bars.
- Smooth scroll reveals, sticky nav, and a reduced-motion fallback.

## Run locally

It's a static site — just open `index.html`, or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure & content |
| `styles.css` | Fine-dining theme, layout, animations |
| `script.js` | Custom cursor, reveals, theming |
| `PERSONALITY-ANALYSIS.md` | The strengths-based profile the site is built on |
